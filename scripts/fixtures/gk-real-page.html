Frequently asked questions

More about GravityKit for developers

How customizable is GravityKit for developers?

Very. GravityKit is built with developers in mind. You can customize everything using hundreds of actions and filters. GravityView also includes a REST API that respects field-level visibility.

Can I use GravityKit to build custom applications for clients?

Absolutely. GravityKit is perfect for building advanced CRUD apps like job boards, directories, and review sites. It’s fast to deploy, easy for clients to use, and simple for you to extend.

Will GravityKit slow down my development process?

Quite the opposite. GravityKit saves hours of development time by providing a flexible, ready-made framework for building data-driven applications within WordPress.

Is GravityKit compatible with other Gravity Forms add-ons?

Yes. GravityKit integrates seamlessly with other Gravity Forms tools, including Gravity Flow, Gravity PDF, and other third-party plugins. You can build end-to-end workflows with full confidence.

Where can I find technical documentation and support?

We maintain a robust knowledge base with developer documentation, and an active GitHub repo. Plus, our support team is always there to help if you hit a snag.
